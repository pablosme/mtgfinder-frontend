01 / Quick start

From a name to a focused search

Dragon /type=creature /color=R

Dragon is the name text. /type=creature adds a type filter, and /color=R adds a red color filter.

  1. Enter a card name or part of one. Results appear as you type after a short pause. A name is required, even when using filters.
  2. Add a command. Type / or use the slash button in the search box. Choose a filter, then enter its value after =.
  3. Open a result. Click a card, or use ↑ and ↓ to highlight it and Enter to open its details.

You can use the search box at the top of this page while reading. The arrow keys and Enter also work in the filter menu. Press Esc to close suggestions.

02 / The basics

Write commands as /filter=value

Separate commands with spaces
Keep each command together: /rarity=rare. Do not add spaces around the equals sign. Commands can go before or after the name; text outside the commands becomes the card-name search.
Quote values that contain spaces
Use double quotes around the entire value: /type="Legendary Creature" or /set="Limited Edition Alpha". Single quotes do not group words. Close the double quote before adding another command.
Keep special characters inside quoted values
Inside a double-quoted value, write \" for a literal double quote and \\ for a literal backslash.
Use the supported command names
Command names are case-insensitive: /TYPE=creature and /type=creature use the same filter. /color= and /colors= are aliases. Keep underscores in names such as /color_identity=.
Keep split-card names intact
The double slash in Fire // Ice is part of the name. It does not start a filter.

04 / Put it together

Combine and repeat commands

Add different commands to narrow several properties in the same search. Repeat a command to supply multiple values; the later value does not erase the earlier one.

Angel /type=creature /keyword=flying /cmc=4
Search the name Angel with creature type, flying and mana value 4.
Lotus /set=lea /collection=232
Search the name Lotus with a set code and collector number.
Elf /color=G /color=B
Supply green or black as alternatives. For both colors in one filter, use Elf /color=G,B instead.
Dragon /rarity=rare /rarity=mythic
Supply two rarity values while searching the name Dragon.

Filters stay with you when moving between the home and header search boxes. Delete a command to remove that filter, or remove all commands to return to a name-only search.

05 / When a search needs a fix

Troubleshooting

“Enter a card name to search.”
Filters alone do not start a search. Add name text, such as Dragon /color=R.
Unknown filter or missing value
Type / to pick a supported command. Use /type=creature, with the slash, equals sign and a nonempty value. Syntax errors pause searching until corrected.
A quoted value is unfinished
Check that the whole value is enclosed in double quotes. For example, write /keyword="first strike".
A color, rarity, format status or mana value is rejected
Use U for blue, mythic for mythic rare, not_legal with an underscore, and a nonnegative number such as /cmc=3. Check the command reference for details.
No cards found
Check the name, remove filters one at a time, and look for commands left over from a previous search. Valid syntax can still produce no matches. The examples illustrate syntax and do not guarantee results.
“Unable to search cards. Please try again.”
The search request could not be completed. Try again; this message is separate from a syntax error or an empty result list.
